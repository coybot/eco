# Welcome to Astral

Astral is the autonomous drone platform built on open source. We empower developers, enterprises, and innovators with agentic, agile unmanned systems.

## What is Astral?

Astral provides:

- **Hardware**: NDAA-compliant autonomous drones (Mothership & Scout)
- **Software**: Mission Control app for planning, simulation, and fleet management
- **SDK**: Open source tools for building custom autonomous applications
- **Platform**: Cloud infrastructure for real-time telemetry and AI processing

## Why Astral?

### Open Source First

Our SDK and core software are open source. Build custom applications, contribute improvements, and integrate with your existing systems.

### AI-Native

Every Astral drone supports on-device and cloud LLMs. Use OpenAI, Llama, Mistral, or bring your own AI models for autonomous decision-making.

### Enterprise Ready

NDAA-compliant hardware, fleet management at scale, and dedicated enterprise support. Built for demanding applications in defense, agriculture, infrastructure, and public safety.
